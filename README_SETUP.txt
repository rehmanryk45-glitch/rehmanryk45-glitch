## Preview on your computer
1. Extract the ZIP.
2. Open the `index.html` file in Chrome, Edge or Firefox.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Click **New repository**.
3. For a personal site, name it exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your actual username).
4. Set the repository to **Public** for GitHub Free Pages, then create it.
5. Click **Add file → Upload files** and upload `index.html` from this folder (or upload all files).
6. Click **Commit changes**.
7. Open repository **Settings → Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then Save.
9. Wait for publishing, then use the site URL shown in Settings → Pages. It will normally be `https://YOUR-GITHUB-USERNAME.github.io/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

This starter is a static portfolio. It does not include a secure admin dashboard or database. GitHub Pages is suitable for the public portfolio page; a private admin dashboard/database requires a separate secure backend and proper authentication.
